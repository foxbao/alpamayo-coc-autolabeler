## 三、两处残余瑕疵（都很轻）

### 1. `12` 的 `classify_chunk` 落后于 `14`

`12:81-93` 的 Gentle 分支仍写成无上界形式：

```python
if chunk["average_acceleration"] >= 0.15 and chunk["delta_velocity"] >= 0.8:
    return "GentleAcceleration"
```

因为 `StrongAcceleration`（`>= 1.4`）先判，**结果仍然正确**，不是功能 bug。但 `12` 恰恰是"展示真实 `classify_chunk(chunk)` 输入形状"的那一课，而**排在它后面的 `14`** 反而把 `0.15 <= a < 1.4` 的上界写全了。同一个函数两副面孔，读者会以为 `14` 是"另一种写法"。**建议把 `12` 对齐 `14`**（顺带决定要不要补 `Reverse`——目前 `12` 也没有）。

### 2. `18` 的 docstring 措辞不准

`18:9` 写：

> 第 10–14 课简化了前一部分。

但 `11`（平滑/滞回）与 `13`（短段清理）**不是简化版，它们正是生产实现本身**。建议改成"第 10、12、14 课是简化版；第 11、13 课对应生产的平滑/滞回与短段清理"。
